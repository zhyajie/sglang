# fp8 fn 和fp8 fnuz quant 理论分析

## 1. FP8 格式详解

### 1.1 两种 FP8 格式对比

| 特性 | float8_e4m3fn<br/>(NVIDIA H20) | float8_e4m3fnuz<br/>(AMD MI308) | 影响 |
|------|-------------------------------|--------------------------------|------|
| **标准来源** | NVIDIA/OCP | AMD | - |
| **位结构** | 1符号 + 4指数 + 3尾数 | 1符号 + 4指数 + 3尾数 | 相同 |
| **指数偏移 (bias)** | 7 | 8 | **不同** ⚠️ |
| **最大正数 (MAX_FP8)** | 448 | 240 | **不同** ⚠️ |
| **最小正规数** | 2^-6 ≈ 0.0156 | 2^-7 ≈ 0.0078 | 不同 |
| **最小次正规数** | 2^-9 ≈ 0.0020 | 2^-10 ≈ 0.0010 | 不同 |
| **NaN 支持** | 是 | 否 | 不同 |
| **Inf 支持** | 否 | 否 | 相同 |
| **量化精度 (尾数)** | 3 bits | 3 bits | **相同** |
| **理论相对误差上界** | 6.25% | 6.25% | **相同** |

**计算公式：**


$$
Value = (-1)^S * 2^(E-7) * (1 + M/8)
$$
$$
Value = (-1)^S * 2^(E-8) * (1 + M/8)
$$

## 4. 理论分析

### 4.1 FP8理论误差分析

FP8 (3位尾数) 的**相对量化误差理论最大值**：

- **尾数位数**：3 bits

- **最小步长**：
  $$
  2^{-3} = \frac{1}{8} = 0.125
  $$
  

- **舍入误差最大值**：
  $$
  \frac{1}{2} \times \text{步长} = 0.5 \times 0.125 = 0.0625 = 6.25\%
  $$

这 6.25% 是**单个 FP8 格式**的相对量化误差上界。

#### Scale 不同

```
Per-Token 量化公式：
  scale = max(|X[token, :]|) / MAX_FP8

H20:   scale_fn   = max(|X|) / 448
MI308: scale_fnuz = max(|X|) / 240

scale 比值 = 448 / 240 = 1.8667
```

**影响：** 同一个值被缩放到不同的 FP8 表示范围。

#### 理论舍入误差独立

```
Fn 的量化误差:   ε_fn   ∈ [-6.25%, +6.25%] × |x|
Fnuz 的量化误差: ε_fnuz ∈ [-6.25%, +6.25%] × |x|

两者的误差是独立的，可能方向相反：

最坏情况：
  H20   量化为: x × (1 + 6.25%) = x × 1.0625
  MI308 量化为: x × (1 - 6.25%) = x × 0.9375
  
  绝对 diff = x × (1.0625 - 0.9375) = x × 0.125 = 12.5% × |x|
```

公式：
  max_abs_diff = 12.5% × |原始值|

验证：

### 4.3 绝对 diff ≈ 0.1 的原因

```
绝对 diff ≥ 0.1 的情况分析：

数量: 33,130 (3.16%)
对应原始值范围: [1.45, 8.58]
对应原始值平均: 2.60
平均相对 diff: 6.20%

计算验证：
  原始值 = 2.60
  理论最大 diff = 2.60 × 12.5% = 0.325
  实测平均 diff = 0.155
  
  实测 / 理论 = 0.155 / 0.325 = 47.7%
  
结论：实测值远小于理论上界，完全合理！
```

### 4.4 严谨数学推导

设原始值为 $x$，两种格式的量化过程：

$$
\begin{align}
\text{H20:} \quad & x_{fn} = \text{round}_{FP8}(x / s_{fn}) \times s_{fn} \\
\text{MI308:} \quad & x_{fnuz} = \text{round}_{FP8}(x / s_{fnuz}) \times s_{fnuz}
\end{align}
$$

其中：
$$
s_{fn} = \frac{\max|x|}{448}, \quad s_{fnuz} = \frac{\max|x|}{240}
$$

量化误差：
$$
\begin{align}
x_{fn} &= x + \epsilon_{fn}, \quad |\epsilon_{fn}| \leq 0.0625 |x| \\
x_{fnuz} &= x + \epsilon_{fnuz}, \quad |\epsilon_{fnuz}| \leq 0.0625 |x|
\end{align}
$$

绝对差异：
$$
|x_{fn} - x_{fnuz}| = |\epsilon_{fn} - \epsilon_{fnuz}| \leq |\epsilon_{fn}| + |\epsilon_{fnuz}| \leq 0.125 |x|
$$

**理论上界：**
$$
\boxed{\text{max\_abs\_diff} = 0.125 \times |x|}
$$



## 5. 结论与建议

### 5.1 核心结论

| 结论 | 说明 |
|------|------|
| **差异完全合理** | 绝对 diff 最大 0.59，对应原始值 8.58，相对 diff = 6.9% < 12.5% |
| **符合理论预期** | 97% 的元素绝对 diff < 0.1 |
| **相对误差可控** | 平均相对 diff = 2.95%，P99 = 6.90% |

### 5.2 差异原因总结

```
1. 格式设计差异（根本原因）
   ├─ 指数偏移不同: 7 vs 8
   ├─ 最大值不同: 448 vs 240
   └─ 量化网格位置不同

2. Scale 不同（直接原因）
   └─ scale_fnuz = 1.87 × scale_fn

3. 舍入误差独立（数学原因）
   └─ 两个独立的 ±6.25% 误差可能方向相反
```

### 5.3 绝对 diff 大小规律

```
┌──────────────────────────────────────────────────────┐
│  绝对 diff 与原始值的关系                            │
├──────────────────────────────────────────────────────┤
│                                                      │
│  绝对 diff ≈ 2-7% × |原始值|  (典型情况)            │
│  绝对 diff ≤ 12.5% × |原始值|  (理论上界)           │
│                                                      │
│  • 原始值越大 → 绝对 diff 越大                       │
│  • 相对 diff 保持稳定 (2-7%)                         │
│                                                      │
└──────────────────────────────────────────────────────┘
```
